AI-ready design system

Open source

Tokens are born in the repo, not in Figma. One tokens.json builds the site's CSS variables and a flat JSON that both AI agents and a one-way repo-to-Figma push read — which makes Figma an output of the system rather than its source. Every component ships as a CSS block, a machine-readable spec for agents, and a Storybook story, and the build fails if any of the three is missing, so parity is enforced rather than maintained by hand.

Light and dark come from the same token file: a themed colour carries its dark value beside its light one, and the entire theme is 23 re-aliased tokens with zero per-component rules.
